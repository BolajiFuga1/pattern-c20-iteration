# Pattern iteration program

Web UI (static HTML/JS) and Java reference for the C1–C20 pattern iteration rules.

## Deploy on Vercel

1. Push this repo to GitHub.
2. In [Vercel](https://vercel.com/new), import the repository.
3. Use defaults (no build command; output is the repo root with `index.html`).

Or from this directory, with [Vercel CLI](https://vercel.com/docs/cli) logged in:

```bash
vercel --prod
```
